Frequently Asked Questions
Why does local Git have 6.8 GB if the code is small?
Git is an append-only database. When your Python extraction scripts processed PDFs and generated hundreds of intermediate page crops, Git captured those temporary images as loose binary objects. Furthermore, an interrupted repack operation on June 4th left behind a 1.67 GB orphaned pack file (tmp_pack_ilqDqL).
What does "git prune" and "git gc" actually do?
git prune deletes all loose objects that are unreachable from any existing commit or branch. git gc (Garbage Collection) removes broken temporary pack files, bundles loose files into compressed packs, and optimizes the repository. It will never delete your code or commits.
What happens if I unplug the SSD while working?
The path /Volumes/WD-SN570-1TB/... disappears. Any running command or IDE tab will immediately display "No such file or directory" and stop. It will not break your Mac. However, to prevent database corruption, always pause running processes and click "Eject" in Finder before unplugging.
